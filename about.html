About this site

WW2 Modeller Hub

WW2 Modeller Hub is a free reference website built by and for scale modellers of Second World War aircraft. Every page answers the same question: what do you actually need to know to build a great model of this aircraft?

The site consolidates squadron histories, pilot records, paint codes across all four major brands, kit reviews, aftermarket guides, weathering recipes and airfield maps into a single fast-loading reference — so you spend more time at the workbench and less time searching across forums and out-of-print books.

About the author

This site is researched and written by a scale modeller with a long-standing focus on Battle of Britain RAF and Luftwaffe subjects. Sources include Air Historical Branch records, RAF Museum archive, IWM Collections, pilot memoirs (First Light, Nine Lives, The Last Enemy, Gun Button to Fire, Spitfire Pilot) and MAP colour documentation. Paint code recommendations are cross-referenced against MAP charts and manufacturer reference samples. All kit reviews reflect genuine build assessments — never influenced by commission rates.

The Hurricane reference

The Hurricane page covers all 22 BoB squadrons with named pilots; eight key paint colours across Humbrol, Tamiya, Vallejo and AK Interactive; nine major kits; seven aftermarket categories; a sector station map; animated 113-day timeline; radar comparison tool; nine flying survivors; 17 books; and five extended pilot biographies. It remains the most comprehensive free Hurricane modelling reference available online.

The Spitfire reference

The Spitfire page covers all 19 BoB Spitfire squadrons — from Sailor Malan's Tiger Squadron at Hornchurch to 609's West Riding Auxiliaries at Middle Wallop. 180+ named pilots, full paint codes across four brands, eight kit reviews, six aftermarket categories, six station weathering recipes, survivors including AR501 at Shuttleworth, 14 books and five extended pilot stories including Geoffrey Wellum and Richard Hillary.

How the site is built

Plain HTML, CSS and JavaScript — no frameworks, no databases, no server costs. Hosted on GitHub Pages, loading under two seconds on mobile. Maps use OpenStreetMap via Leaflet.js. Photos from Wikimedia Commons under Creative Commons licences. All data is hand-researched from primary sources.
